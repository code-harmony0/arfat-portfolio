Problems from production, and what I did.

Mostly from Zonesso. Each one is a symptom, a cause and a fix I can walk you through.

ProblemWhat brokeWhat I did

Google Play's 16 KB page-size ruleAndroid

Play started requiring apps to run on devices with 16 KB memory pages. Native code built for 4 KB pages can fail on them, and releases get blocked.

Moved the Android build to NDK 28 and target SDK 36 so the native code the app ships meets the rule.

Users logged out when the network droppedChat and auth

Network drops and sending the app to the background signed people out of their account.

The chat socket's disconnect handler was changing login state. A disconnect is a transport event, not an auth event, so login state now changes only through the login and clear-data flows.

An App Store rejectioniOS

Apple rejected a build over App Tracking Transparency compliance and in-app-purchase discoverability.

Fixed both.

In-app purchase breaking on iOS 18Payments

In-app purchases broke on iOS 18.

Upgraded react-native-iap to v13, patched it for iOS 18 compatibility and fixed the account token to be a UUID.

Notification taps on a cold startPush

Notification taps that arrived before the app was ready.

Added deep-link retry, so a tap during a cold launch still lands on the right screen.

Samsung Pay missing on release buildsAndroid

Samsung Pay on release builds, where code shrinking can strip what the SDK needs.

Wrote explicit ProGuard keep rules for the SDK, so it survives release shrinking.

Four habits sit behind these: plan before code, write down why, make releases boring, leave the team stronger. Zonesso case study ↗

The brief

A Dubai vehicle marketplace needed a mobile app people could browse, post and pay in. I became its only mobile engineer, so architecture, payments, testing and every release sat with me.

How I approached it

Listings, posting an ad and checkout decide a marketplace, so I put structure around those three first. Server state moved to TanStack Query and app state to Jotai. Five payment methods went behind one checkout.

What shipped

A live iOS and Android app, a React Native upgrade run as a cleanup, a CI-tested release pipeline, and a scope that has grown to the Next.js site and admin dashboard.
